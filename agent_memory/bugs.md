## 观察项

- Polymarket 正式结算 API 的字段和可用性仍需在长期运行中持续核对，不能把不确定结果当作结算。
- 钱包、签名、真实订单和链上写操作属于后续阶段，本任务不得引入。
- v0.5.0 正式长期 PAPER 运行、剩余故障矩阵和性能/容量验证仍是未完成项；不能把当前自动测试或单一账本故障演练通过当作长期验证完成。
- 自动化浏览器使用的代理无法直接建立到裸公网IPv4的HTTPS隧道；服务器本机认证前后检查、Let's Encrypt外部验证、云防火墙状态及独立公网401抓取均已通过，但手机和电脑真实浏览器的最终登录仍需用户人工确认。
- 当前固定IPv4证书有效期约6天；Certbot定时器和续期部署钩子已配置且干运行通过，仍应在正式长期验证中观察真实续期及Nginx重载，避免只依赖一次模拟。
- 当前Nginx Basic Authentication只适用于单用户TEST；若未来进入LIVE，必须升级身份认证、会话、CSRF和审计边界，不能因为本次HTTPS冒烟通过就视为实盘安全完成。
- 全市场分页扫描可能显著增加订单簿请求量和 WebSocket 订阅 Token 数，需在 v0.5.0 长时间验证中观测官方速率限制与订阅容量；这不是本轮用固定上限掩盖的筛选规则。
- 约2,000至2,400 Token完整规模的短时盘口就绪、有界关停和三轮连续断线恢复已通过，但长时间保持、长期窗口内断线和重复扫描稳定性仍需验证。
- 10分钟和15分钟PAPER运行均未观察到可确认的低价Token市场成交；受控运行时测试已覆盖纸面买入、自动卖单、首次卖出撤买和健康账本，但真实公开行情触发仍需在长期运行中观察。
- 周期验证只负责发现问题、暂停和阻止重新运行，不会自动修复不一致账本；未来服务器运维仍须先备份现场、定位差额并人工核对修复，禁止关闭验证或强改状态绕过门槛。
- 进程资源指标已可留证，但当前Mac短时结果不能替代未来Linux服务器基线；正式长期窗口前不设置缺乏证据的内存自动失败阈值。
- 有界重试能避免单个暂时错误立即丢弃扫描进度，但不能证明真实Gamma/CLOB接口长期无压力；需用新增请求、重试、限流和临时错误计数确定长期频率，持续故障在3次请求后仍会保守失败。

## 已处理

- Linux服务器已完成构建、网页/API、SQLite持久化及同库重启冒烟；应用3000只监听本机，固定IPv4 HTTPS与登录认证生效，云防火墙原3000临时规则已删除。
- 首次Linux镜像构建在运行阶段第二次执行`npm ci --omit=dev`时，`better-sqlite3`预构建回退到本地编译并因精简镜像缺少工具链而失败；没有容器或数据库启动。现改为在带最小编译工具链的依赖阶段安装一次，裁剪开发依赖后只复制生产`node_modules`到非root运行镜像，服务器重建已通过。
- 真实浏览器首次点击开始按钮时，前端给无请求体的POST统一附加`application/json`，Fastify因空JSON拒绝请求；现只在存在请求体时设置JSON请求头，并重新执行真实按钮交互验收。
- 本轮首次调用环境提供的`pnpm`包装器时，依赖策略因`esbuild`构建脚本未批准而中止并生成两个未跟踪的pnpm文件；改用仓库现有依赖的直接可执行入口完成验证，生成文件已移除，未改动依赖锁。
- 最终UI首审发现筛选只等待下次扫描才生效、手动下单可绕过筛选、最高价格曾放宽到99¢、持仓统计只取100项、任意Token选择可写库、旧持仓缺元数据、非法旧配置与滑杆不一致、冻结撤单失败时选择先写入、轮询覆盖未保存草稿以及控件标签/触控面积问题；现已以即时双入口校验、`1¢`至`3¢`整数约束、全量正数量持仓查询、当前候选校验、迁移回填和候选回退、启动失败关闭、事务前安全断言、脏表单保护及可访问性修正处理并补回归测试。
- Standards复审发现浅色主按钮12px白字与原青绿色背景对比度约3.88:1；现改用已有深青色变量，对比度约5.41:1，达到WCAG AA普通文字门槛。
- 320px浏览器宽度初检时，`html/body`的固定最小宽度与竖向滚动条叠加产生横向滚动；已移除多余最小宽度并在配置关闭/展开两种状态复验`scrollWidth=clientWidth`。

- `CandidateService.refresh()`原先在清理活动扫描标记前生成返回快照，导致已等待完成的手动刷新仍显示`scanning=true`；现改为清理后再生成快照，并固定覆盖暂时失败保留候选及后续恢复。
