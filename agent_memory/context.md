# Context

## 项目

- PM-SMALL：基于公开 Polymarket 数据的 PAPER 交易闭环项目。
- GitHub `origin/main` 当前仍为 `799831d`；本地 `main` 已在该基线之上完成 v0.4.0 结算闭环和全市场分页扫描，尚未推送。

## 边界

- 当前阶段已完成 v0.4.0 纸面结算闭环，v0.5.0 长期 PAPER 验证正在开发。
- 纸面闭环和长期验证完成前，不接入钱包、不提交真实订单、不执行链上写操作。
- 保持现有实盘执行器禁用状态，数据缺失或状态不确定时保守处理。

## 验证目标

- 事件结算、纸面赎回、资金回收具备幂等、资金守恒、审计记录和重启恢复能力。
- 正式结果只接受 `closed=true` 且 UMA 状态为 `resolved`/`settled`；支持 `1/0` 与 `0.5/0.5` 纸面回收。
- 周期只读验证覆盖 SQLite、资金守恒、订单成交范围、挂单占用、持仓卖单覆盖和结算残留；失败时保留现场，除卖单减仓外冻结自动账本变更，修复通过前不得恢复 `RUNNING`。
- 长时间运行、完整故障注入、全市场接口速率和 WebSocket 容量仍需真实验收；自动测试不能替代这些结果。

## UI约定

- `MAX_MARKET_DURATION_DAYS` 表示市场从开放到结束的总时长上限，不是剩余时长。
- 最终 UI 使用离散滑杆节点 `1、7、14、30、60、90、120、180、360、365` 天，默认 30 天；与最终 UI 设计一起实现，本阶段不提前修改界面。
