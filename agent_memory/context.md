# Context

## 项目

- PM-SMALL：基于公开 Polymarket 数据的 PAPER 交易闭环项目。
- 当前唯一进度依据：GitHub `origin/main`，已同步到提交 `799831d`（v0.3.0 自动纸面运行/恢复基线）。

## 边界

- 当前阶段已完成 v0.4.0 纸面结算闭环，下一阶段是 v0.5.0 长期 PAPER 验证。
- 纸面闭环和长期验证完成前，不接入钱包、不提交真实订单、不执行链上写操作。
- 保持现有实盘执行器禁用状态，数据缺失或状态不确定时保守处理。

## 验证目标

- 事件结算、纸面赎回、资金回收具备幂等、资金守恒、审计记录和重启恢复能力。
- 正式结果只接受 `closed=true` 且 UMA 状态为 `resolved`/`settled`；支持 `1/0` 与 `0.5/0.5` 纸面回收。
- 完成与改动范围匹配的类型检查、测试、构建，并为后续长期纸面验证留下可执行基础。
